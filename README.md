# AI-adaptive-manufacturing-dataset
Supplementary dataset accompanying the manuscript "Adaptive Closed-Loop AI Control Architecture for High-Precision Advanced Manufacturing." Contains 48,000 manufacturing observations from CNC machining and Selective Laser Melting (SLM) under Conventional and AI Adaptive Control for reproducibility and research.
# Smart Manufacturing Dataset: AI Adaptive vs. Conventional Control

This repository hosts the dataset evaluating surface roughness measurements (µm) across CNC and SLM manufacturing processes, comparing Conventional Control methods against closed-loop AI Adaptive Control.
